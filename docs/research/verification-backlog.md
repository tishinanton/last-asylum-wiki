# Очередь проверок / Verification Backlog

Эта очередь является частью опубликованной документации. Запись закрывается
только доказательством из актуального клиента или более надёжного источника.
Для снимка из игры сохраняются дата, версия клиента, платформа, язык, регион и
сервер.

## Отвергнутые до появления доказательства / Rejected pending evidence

- `Research Lab level 15 is required for Alliance Duel research` — не найдено
  ни в одном из семи проверенных источников.
- `Survival Battle resets at 00:00 UTC` — сейчас подтверждено только 00:00:00
  без зоны.
- `Each Alliance Duel daily win always gives exactly one trophy` — [S1]
  описывает разные winning-point значения фаз, точная модель неизвестна.
- `The two events have a formal double-scoring mechanic` — подтверждён лишь
  совет синхронизировать расход ресурсов.
