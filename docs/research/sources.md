## Правила цитирования / Citation policy

1. Для числовой таблицы указывать конкретный `S#` и дату доступа.
2. При расхождении источников показывать оба значения без усреднения.
3. Снимок актуального игрового клиента имеет приоритет только для указанной
   версии, региона и сервера; эти метаданные нужно сохранять.
4. Поисковый сниппет, пересказ и недоступная страница не подтверждают числа.
5. Отсутствие утверждения в источнике не доказывает обратное.
6. Совпадение одного действия в двух событиях подтверждает возможность
   независимого зачёта только в одновременно активных окнах, но не формальную
   связь событий.
